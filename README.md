# Integra

Plataforma educativa para docentes de zonas rurales del Guaviare, Colombia.

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desarrollo local

Requisitos: Node.js y npm instalados ([instalar con nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Instalar dependencias
npm i

# Iniciar el servidor de desarrollo
npm run dev
```
